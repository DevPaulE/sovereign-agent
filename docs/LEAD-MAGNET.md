# LEAD MAGNET — the free Dæmon Audit

> Hormozi's test: give away something with **hard cost to a competitor** but **inconsequential cost to you**, that **qualifies** the lead and **sells the next tier**. Dell's test: **free value first**, then the paid conversation. This is that.

## What it is

**A free one-page Dæmon Audit, run for one business in minutes.**

The owner points the audit at **one thing they already have** (a shared folder, an inbox export, a spreadsheet). A hosted mini-agent (on **exe.dev**) returns:

1. **The gaps** — what breaks when the owner is gone: which decisions only he can make, which walk out with him.
2. **The one automation** — the single highest-value workflow to capture first, with a rough hours-back number.
3. **The proof** — every finding cites the file it came from. It can't be hand-waved.

One page. No login beyond a link. It lands in their inbox.

## Why it's inconsequential to you and hard-cost to a competitor

| | You | A generic AI consultant |
|---|---|---|
| The agent | already built (the dæmon) | must build one |
| The gate | `GATE.md` + `check-ddg.py` | none |
| The compute | an exe.dev sandbox, pennies, ephemeral | a cloud bill |
| Marginal cost | ~minutes | hours of unbilled work |

Hormozi's exact logic: *give away things that have a hard cost to competitors that they cannot afford.* A free, **verifiable** audit is hard for a words-only consultant to match — and it's your system running.

## The qualification (built into the magnet)

Not for everyone. The audit runs only if they **name a trigger**: an exit on the horizon, a key person about to leave, a recurring bottleneck they'd pay to remove. No trigger, no audit. That's Hormozi's "give the amazing thing only to the qualified" — the friction self-selects.

## The ladder (free → paid → rent)

| Rung | What | Price |
|---|---|---|
| **Free** | the Dæmon Audit (one page) | $0 |
| **Core** | the 14-day install — the workflow captured and running | **$5,000 fixed** |
| **Rent** | a dedicated agent-compute box (exe.dev), maintained | monthly |

"Rent real compute" is the top rung, not the magnet — the owner ends up renting **their own agent's** compute, which is the sovereignty story made a subscription.

## How it's built (reuse what exists)

- **Compute:** one **exe.dev** sandbox per prospect (isolated, ephemeral, cheap).
- **The agent:** the dæmon (hemera + the archive + the gates), scoped to one folder.
- **The gate:** `GATE.md` + `scripts/check-ddg.py` — the audit's output is checked, not asserted.
- **Fragments you already built feed it:** the **jiang chatbot** (a doc-answering mini-dæmon) and the **shopbot** (a real SMB workflow) are the two demos the audit can point at.

## Where the audit leads (Dell's framework)

Dell's trust continuum is free value → conversation → paid. The audit is the free value; its last line is the ask: *"If you want this captured and running, I install it in 14 days for $5,000."* The audit **is** the proof and the pitch — the same page.

## The one risk

A free audit that produces a *report* is a lead magnet. A free audit that produces a *running system* is the product given away. **Keep the audit to the map, not the install.** The map shows the gap; the install closes it. That boundary is the whole business.
